## 页面原文

恭喜同学完成前面两个阶段的学习，顺利来到真机项目演练。

教学导师自己真机做过的项目，相当于把经验蒸馏给你（可在简历中写这个项目），写清楚 pipeline 细节，带你学到面试官问题基本都能回答的程度。

建议第三阶段需要的有效学习时长：20-30h 左右。

通过前两个阶段的学习，对于接下来的真机项目所涉及和相关的技术和论文你基本都学完一遍。

接下来只需看完论文和学习笔记，以及真机实验文档，搞清楚 pipeline 细节，确保面试官提问能回答得上来。

目的是熟悉真机的整个流程 + 重要细节，使面试官问你真机相关问题时能答得出来，不用真的做。要求：仔细理解一遍，在脑海中有个印象，能大致复述。
